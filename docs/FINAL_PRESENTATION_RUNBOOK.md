# Final Presentation Runbook

Use this checklist tonight so tomorrow's demo is calm and repeatable.

## Tonight

1. Verify the live app opens cleanly in a browser.
2. Confirm the main demo path works end to end.
3. Make sure everyone knows their speaking part.
4. Keep one fallback video or screenshot set ready.

## Demo Path

1. Open the home page.
2. Show signup or login.
3. Show browse/search flow.
4. Open one item detail page.
5. Show dashboard or profile behavior.
6. Mention the current roadmap only after the live demo works.

## What To Verify Before Class

- The deployed site loads.
- Login still works.
- Browse pages are not broken.
- Item detail pages open.
- Dark mode and language switching do not break the layout.
- Images and cards render correctly on desktop and mobile widths.
- The README and main docs still point to the correct repo and live demo.

## Speaking Order

- Speaker 1: project overview and problem statement.
- Speaker 2: core user flow and demo actions.
- Speaker 3: technical implementation and notable features.
- Speaker 4: testing, deployment, and reliability notes.
- Speaker 5: roadmap, closeout, and final ask.

## Backup Plan

- If the live site fails, switch to screenshots immediately.
- If a flow breaks, demo the closest working path and explain the issue briefly.
- Do not spend class time debugging from scratch.

## Last-Minute Focus

- Practice the demo once without stopping.
- Remove any extra browser tabs.
- Keep the live URL and repository URL ready to paste.
- Save every screenshot or note used as evidence.

## Final Message

The goal tomorrow is not to show everything. The goal is to show one clean, believable product story that works.
